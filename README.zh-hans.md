# Ember

由 **Orthic Labs** 独立维护的开源照片图库与非破坏性 RAW 编辑器。Rust 处理引擎支持 macOS、Windows、Linux 与 WebAssembly；桌面工作区使用 React/Tauri。

- 照片导入、图库管理、非破坏性编辑与导出。
- 自动调整、蒙版与 AI 工具；实际可用性以当前构建与模型配置为准。
- CLI、控制通道与 MCP 共用命令系统。

项目仍在开发中。功能状态与验证要求见 [英文说明](README.md)、[路线图](ROADMAP.md) 与 [功能跟踪](docs/parity-checklist.md)。
